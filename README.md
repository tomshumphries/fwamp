# FWAMP! - Fantasy World Adventures Mega Park! The Musical

Promotional website for FWAMP!, a musical comedy heading to the Edinburgh Festival Fringe 2026.

**Live site**: https://tomshumphries.github.io/fwamp/

## Development

```bash
npm install
npm run dev       # local dev server
npm run build     # production build
npm run preview   # preview production build
```

## Deployment

Pushes to `main` auto-deploy to GitHub Pages via GitHub Actions.
