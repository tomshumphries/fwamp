# FWAMP Brand Guidelines

## Fonts

| Role | Font | Status |
|------|------|--------|
| Primary (headings, logo) | Bobby Jones Soft | Loaded via `@font-face` |
| Secondary | One Little Font | Not yet loaded — system font fallback |
| Body | Gabriel Sans Condensed | Not yet loaded — system font fallback |

## Colours

### Text Colours
- **Pink**: `#ff66c4` (with burgundy outline `#80004e`)
- **White**: `#ffffff` (with burgundy outline `#80004e`)
- **Blue**: `#87b0e1`
- **Burgundy** (outlines): `#80004e`

### Backgrounds
- **Yellow**: `#ffde59` (primary background for branding)
- **Peach/orange**: `#ffb68a` (gradient with yellow)
- **Website background**: gradient from `#ffde59` to `#ffb68a`
